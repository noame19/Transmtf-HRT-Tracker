# HRT Tracker

HRT Tracker 是一个网页端的激素替代疗法（HRT）追踪工具。它根据体重、身高和给药方式模拟雌二醇等激素在体内的实时浓度曲线，并基于化验结果反推出个人代谢节奏。数据全部保存在浏览器的 `localStorage` 中，离线仍可使用；可选的云同步会把记录端到端加密后上传到配套服务器。

English version: [README.en.md](./README.en.md)

## 给药方式

- **注射（肌注）**：戊酸雌二醇（EV）、苯甲酸雌二醇（EB）、环戊丙酸雌二醇（EC）、庚酸雌二醇（EN）、十一酸雌二醇（EU，长链）、黄体酮（PROG）。
- **口服**：雌二醇（E2）、戊酸雌二醇（EV）、醋酸环丙孕酮（CPA）、比卡鲁胺。
- **舌下**：雌二醇（E2）、戊酸雌二醇（EV）；含服时长与吸收参数 θ 提供「快速/随手/标准/严格」四档参考值，也可自定义 θ。
- **透皮凝胶**：Oestrogel、Estreva、EstroGel、Divigel、DIY 五种预设产品；涂抹部位覆盖手臂、大腿、阴囊、腹部；可记录擦洗时间，以及与防晒霜 / 润肤剂的叠加。
- **透皮贴片**：贴上与撕下两条配对事件（通过共享 `companionGroupId` 关联），引擎据此计算佩戴时长。
- **直肠（栓剂）**：黄体酮栓剂的睡前给药途径。

## 浓度曲线与个性化拟合

- **E2（pg/mL）曲线**：根据体重、身高、给药方式与事件时间计算总曲线，区分 E2 家族（E2/EB/EV/EC/EN/EU）与抗雄（CPA/比卡鲁胺）。
- **化验拟合个人参数**：录入化验结果后，从人群先验出发反推该用户的代谢节奏；可用化验单位 `pg/mL` 或 `pmol/L`。
- **三套校准模型**：EKF、Ornstein–Uhlenbeck Kalman（含 RTS 顺滑）、Hybrid-MIPD（MAP + Student-t 鲁棒似然 + 拉普拉斯协方差 + GP 残差修正）；时间模式可在「因果（加新数据不改写过去）」与「回溯（新数据改写过去）」之间切换。
- **置信带**：当存在个人模型时，曲线下方同时给出 95% CI 与 68% CI 两层带；E2 主曲线还会在 E2 卡片上叠加 Raw / Baseline / 个人值三档数值。
- **基线内源 E2**：给药前的化验值会作为内源性雌二醇基线叠到曲线，避免把背景误读为药源。
- **CPA → E2 抑制**：可选开关，按 Hill 方程把 CPA 对 E2 清除率的抑制施加到曲线与置信带上。

## 给药计划

- **三种周期**：每日、每 N 天、每周（多天可选）；同一计划可设多个服药时刻。
- **下一计划预览**：首页每张药物卡右侧显示「下次计划 + 大号时间 + 相对日 + 上次用药」。
- **提前提醒分钟数**：0–30 分钟，与 Android 通知栏对接。

## 提醒与合规

- **到点提醒**：通知权限开启后，Android 端会在通知栏弹出；点通知一键确认。
- **迟到状态**：过点 1h 起切换为「已过服药时间」，4h 后自动收起。
- **顺延与跳过**：在横幅里直接「顺延 1 天 / 顺延 2 天 / 跳过」当前计划。
- **合规检查**：当某个药物分类（雌激素/抗雄/孕激素）既有计划又有近期记录、且主用方式与计划不符时，顶端显示合规 banner 并列出最近 4 条样本。

## 历史与操作

- **记录页**：按时区本地日历分组，支持长按进入多选与批量删除；贴片可在「贴片移除」按钮一键补一条撕下事件。
- **批次录入**：同处方一次填入多天记录，逐条确认后入库。
- **热力图**：按药物分类着色的日历；多日贴片自动连成一段；今天用边框标出。
- **用药计划页**：启用/停用、编辑、删除；同一药物分类只允许同时启用一条计划。

## 数据导出与备份

- **AI 咨询导出**：按日期范围导出文本快照（个人信息 + 当前计划 + 给药日志 + 化验 + 90 天达标率 + 本月顺延数），并指定 AI 按当前界面语言回复，便于咨询医师或 LLM。
- **加密导出**：用随机生成的密码 + PBKDF2(100k) + AES-GCM 加密整份数据，密码由导出方保管。
- **JSON 导入**：v2/v3/v4 三种 schema；导入时自动补齐贴片配对、整理孤儿事件。
- **自动备份**：破坏性操作（导入、清空）前静默备份到 `Downloads/HRT Tracker/`；180 天滚动清理。

## 云同步与账号（可选）

- **账号**：用户名密码 + Cloudflare Turnstile；可绑定 OIDC（外部身份提供者）。
- **端到端加密同步**：本地数据先经安全密码加密再上传；本地离线仍可用。
- **设备列表**：在账户页查看并下线已绑定设备。
- **安全密码**：本地 cookie 自动续期；过期后需重新输入。

## 隐私与展示

- **首启免责声明**：首次启动显示一次；设置页可随时重看。
- **主题色 / 暗色模式**：樱花等预设；玻璃拟物风格（带毛玻璃质感的卡片）。
- **分享图**：一键把当前浓度曲线渲染为 PNG。
- **公共统计**：设置页内含公共统计面板（累计用户、近 7 天同步次数、数据库规模、最近更新）。
- **基础信息**：HRT 起始日期、过敏 / 禁忌症、生日。

简体中文、繁体中文、英语、日语。

## 打包与部署

桌面端与 Android 端通过 GitHub Actions 构建。`tauri:dev` 与 `tauri:build` 在本地需要 Rust 与 Android SDK。代码可自行部署到任意静态站点或 CDN，无需额外授权；公开部署时请保留指向本仓库的链接与 MIT License。

## 本地运行

```bash
npm install
npm run dev
```
